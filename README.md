# Central Jual Emas (Concept Project)

Landing page konsep untuk layanan jual emas dengan fokus edukasi dan konversi.  
Built by a solo developer (AI-assisted) using modern web tools.

## Preview
- Demo: https://central-jual-emas.netlify.app/
- Admin: https://central-jual-emas.netlify.app/admin.html

## Highlights
- Kalkulator estimasi harga emas berdasarkan berat dan kadar
- Update harga emas otomatis via API (XAUSD / world gold data)
- CTA WhatsApp, testimoni, FAQ, dan lokasi

## Tech Stack
HTML, CSS, JavaScript, React, Vite, API

## Notes
Data pelanggan/cabang/testimoni di project ini menggunakan mock data untuk kebutuhan desain.

## Run Locally
```bash
npm install
npm run dev
```
